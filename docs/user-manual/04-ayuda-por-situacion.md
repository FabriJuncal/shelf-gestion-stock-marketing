# Ayuda por situación

Usá esta guía cuando ya sabés qué querés resolver, pero no cuál función corresponde.

| Situación                                  | Qué revisar primero                                                                                           | Quién puede resolverla                                                |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| No encuentro un activo                     | Buscá por nombre, categoría, etiqueta, ubicación o código; revisá si está en custodia o en una reserva.       | Propietario, Administrador; Autoservicio/Base según visibilidad.      |
| El activo está prestado sin fecha          | Revisá la custodia y confirmá quién lo tiene.                                                                 | Propietario/Administrador; Autoservicio sólo su propia custodia.      |
| Necesito apartar activos para una fecha    | Creá una reserva con período, custodio y activos disponibles.                                                 | Propietario/Administrador; Autoservicio y Base sólo para sí mismos.   |
| No puedo entregar o devolver una reserva   | Confirmá el rol y el estado de la reserva. Base requiere un Administrador; Autoservicio opera sólo lo propio. | Según rol.                                                            |
| No veo Reportes o Configuración            | Verificá que seas Propietario o Administrador. Un enlace directo no cambia los permisos.                      | Propietario/Administrador.                                            |
| Necesito comprobar el inventario físico    | Iniciá o realizá una auditoría asignada.                                                                      | Propietario/Administrador; Autoservicio/Base sólo si están asignados. |
| Quiero cargar muchos activos               | Usá la importación CSV y probá primero un lote pequeño.                                                       | Propietario/Administrador.                                            |
| No veo una función de códigos o auditorías | Confirmá el rol, el plan o complemento y el estado de activación en la pantalla.                              | Propietario o quien administre el espacio.                            |

Para instrucciones detalladas, seguí los enlaces oficiales de los capítulos anteriores. Si el comportamiento no coincide con el manual, registrá la ruta, el rol, el idioma y el texto observado: esa información permite verificarlo sin adivinar.

**Capturas:** `PENDIENTE`. Esta guía no sustituye evidencia visual autenticada.
