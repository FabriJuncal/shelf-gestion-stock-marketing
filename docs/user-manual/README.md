# Manual de usuario de Shelf

Esta guía acompaña a quienes usan Shelf desde el primer acceso hasta las funciones avanzadas. Resume el objetivo de cada tarea y enlaza a la base de conocimiento oficial cuando allí ya existe una explicación completa.

## Cómo usar este manual

1. Empezá por [Primeros pasos](01-primeros-pasos.md).
2. Continuá con [Operación habitual](02-operacion-habitual.md).
3. Si administrás el espacio, seguí con [Administración y avanzado](03-administracion-y-avanzado.md).
4. Consultá [Ayuda por situación](04-ayuda-por-situacion.md) si ya tenés un problema concreto.
5. Seguí el recorrido que corresponda a tu rol.
6. Abrí los enlaces oficiales para el detalle o los casos especiales.
7. Si una opción no aparece, comprobá primero tu rol y los requisitos que indica cada capítulo.
