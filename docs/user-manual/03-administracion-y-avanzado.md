# Administración y funciones avanzadas

**Para:** Propietario y Administrador.
**Objetivo:** controlar el inventario a escala, revisar su estado y mantener reglas claras para el equipo.

## Auditorías

Una auditoría compara lo que debería estar en una ubicación con lo que se encuentra físicamente. Preparala cuando ya existan activos identificables y, de ser posible, códigos QR. Definí alcance, responsable y fecha; al terminar, revisá faltantes, hallazgos inesperados y el informe.

[Run Your First Audit](https://www.shelf.nu/knowledge-base/run-your-first-audit) contiene el recorrido completo y los requisitos de disponibilidad.

- Propietario y Administrador pueden crear, gestionar y cerrar auditorías conforme al plan disponible.
- Autoservicio y Base pueden realizar únicamente auditorías que se les asignen; no deben administrar, borrar ni crear la auditoría.

**Captura:** `PENDIENTE` — lista, detalle y escaneo de auditoría por rol.

## Reportes y exportaciones

Usá reportes para responder una pregunta, no sólo para descargar datos: qué está vencido, qué activos se usan más, quién tiene custodia o cómo evolucionan las reservas. Elegí el período antes de interpretar el resultado y verificá qué filtros admite cada reporte.

[Getting Started with Reports](https://www.shelf.nu/knowledge-base/getting-started-with-reports) explica reportes, períodos, filtros y CSV/PDF.

Los reportes y sus exportaciones están disponibles para Propietario y Administrador. Autoservicio y Base no deben esperar ver Reportes en el menú ni acceder mediante un enlace compartido.

## Importar y exportar activos

La importación sirve para incorporar o actualizar muchos activos de manera controlada. Descargá o revisá la plantilla, probá primero un lote pequeño y conservá los encabezados requeridos. Para actualizaciones, recordá que algunos valores no se cambian por importación.

La referencia oficial para crear registros está en [Importing Assets to Shelf: CSV Guide](https://www.shelf.nu/knowledge-base/importing-assets-to-shelf-csv-guide); para actualizar existentes, usá [Bulk Updating Assets via CSV](https://www.shelf.nu/knowledge-base/bulk-updating-assets-via-csv). Para exportar, elegí el formato apropiado según [Exporting Data from Shelf](https://www.shelf.nu/knowledge-base/export-exporting-workspace-data-from-shelf), comprobá filtros y selección antes de compartirlo y no reimportes un respaldo como si fuera una plantilla.

## Equipo, roles y propiedad

Asigná el menor permiso que permita a cada persona trabajar. Revisá los roles al incorporar, cambiar de función o retirar acceso. Propietario conserva decisiones de propiedad y configuraciones sensibles; Administrador opera el equipo dentro de los permisos delegados.

La [matriz oficial de roles y permisos](https://www.shelf.nu/knowledge-base/user-roles-and-their-permissions) es la referencia para cada acción. Autoservicio y Base no administran integrantes, roles, configuración general ni reportes.

## Configuración responsable

Antes de cambiar configuraciones compartidas, explicá al equipo qué efecto tendrá sobre reservas, visibilidad o avisos. Separá preferencias personales de reglas del espacio. No cambies límites, suscripciones, propiedad o integraciones sólo para resolver una tarea cotidiana: confirmá el propósito y el alcance.

Usá campos personalizados, horarios de trabajo, notificaciones y preferencias sólo cuando apoyen un proceso claro. Si una función depende de plan o complemento, confirmalo en la pantalla y en su artículo oficial vigente.

## Comprobación

- ¿La auditoría tiene alcance y responsable claros?
- ¿El reporte elegido responde una pregunta concreta?
- ¿La importación se probó con un lote pequeño?
- ¿Cada integrante tiene el permiso mínimo necesario?
- ¿Las configuraciones compartidas se comunicaron antes de cambiarlas?

Las capturas, revisión con usuarios y publicación pertenecen a S05.
