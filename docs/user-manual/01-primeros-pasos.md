# Primeros pasos con Shelf

**Para:** Propietario y Administrador. Incluye qué puede hacer una persona con
rol Autoservicio o Base.
**Objetivo:** dejar el espacio listo para que el equipo pueda encontrar, registrar y responsabilizarse por sus primeros activos.

> Esta guía orienta el recorrido. Cuando una tarea tiene una explicación oficial completa, se enlaza esa fuente en vez de repetirla.

## 1. Identificá tu rol antes de empezar

Tu menú y las acciones disponibles dependen de tu rol:

- **Propietario:** prepara el espacio, define reglas y conserva acciones que afectan la propiedad o la suscripción.
- **Administrador:** administra el inventario y el equipo; puede realizar la mayor parte de la operación diaria.
- **Autoservicio:** puede trabajar sobre sus propias reservas y operaciones permitidas, sin administrar el espacio completo.
- **Base:** puede consultar activos y crear solicitudes propias; un Administrador realiza la entrega y devolución por esa persona.
- **NRM:** no inicia sesión. Es un registro de una persona a quien se le puede asignar custodia.

Consultá la [matriz oficial de roles y permisos](https://www.shelf.nu/knowledge-base/user-roles-and-their-permissions) si necesitás confirmar quién puede usar una función. Si no ves una opción que este manual menciona, no intentes reemplazarla con otra acción: verificá el rol, el espacio y los requisitos indicados por la aplicación.

## 2. Reconocé la pantalla de inicio

Al ingresar, buscá el checklist de bienvenida. No es un examen: es la forma más corta de preparar el inventario con una base ordenada.

Para Propietario y Administrador, el orden recomendado es:

1. crear o importar activos;
2. organizar categorías y etiquetas;
3. sumar integrantes o registrar personas sin acceso;
4. asignar custodia cuando alguien queda responsable de un activo;
5. agregar campos personalizados sólo cuando ya sabés qué información falta.

Las personas Autoservicio y Base pueden usar este capítulo para entender cómo se organiza el espacio, pero no necesitan completar las tareas administrativas.

**Captura:** `PENDIENTE` — inicio y checklist, rol Propietario/Administrador, español. Se incorporará sólo después de verificar una sesión real.

## 3. Registrá el primer activo

Empezá por un activo real y reconocible: por ejemplo, una computadora, cámara, herramienta o equipo que el grupo usa con frecuencia. Desde Activos, elegí la opción para crear un activo y completá los datos que ayuden a encontrarlo: nombre, categoría, ubicación y, si corresponde, etiqueta.

No intentes cargar todo el inventario perfecto en el primer día. El primer objetivo es que una persona del equipo pueda buscar ese activo y saber dónde debería estar.

- Para crear activos uno por uno, seguí [Adding New Assets](https://www.shelf.nu/knowledge-base/adding-new-assets).
- Si ya tenés una planilla, usá la [guía oficial de importación CSV](https://www.shelf.nu/knowledge-base/importing-assets-to-shelf-csv-guide) para revisar columnas y reglas vigentes.

**Resultado esperado:** al menos un activo aparece al buscarlo y tiene la información suficiente para diferenciarlo de los demás.

## 4. Ordená antes de sumar volumen

Usá cada herramienta para una pregunta diferente:

| Herramienta | Pregunta que responde                          | Empezá así                                                                |
| ----------- | ---------------------------------------------- | ------------------------------------------------------------------------- |
| Categoría   | ¿Qué tipo de activo es?                        | Creá pocas categorías que el equipo use todos los días.                   |
| Etiqueta    | ¿Qué característica transversal quiero marcar? | Usá etiquetas para información flexible, como proyecto, prioridad o área. |
| Ubicación   | ¿Dónde debería estar?                          | Registrá el lugar esperado, no una nota informal.                         |
| Código QR   | ¿Cómo lo identifico rápidamente en persona?    | Vinculalo o imprimilo cuando el activo ya tenga un registro confiable.    |

La guía oficial de [categorías](https://www.shelf.nu/knowledge-base/using-categories-to-organize-your-asset-inventory) explica cómo organizarlas. Evitá crear categorías, etiquetas o campos por cada caso excepcional: primero probá el esquema con unos pocos activos.

## 5. Incorporá al equipo de la forma correcta

Antes de invitar, decidí qué necesita hacer cada persona:

- Si sólo necesitás saber quién tiene un activo, registrala como NRM cuando no requiera acceso.
- Si debe reservar, consultar o trabajar con sus propios activos, elegí entre Base y Autoservicio según el nivel de autonomía que necesita.
- Si administra activos, reservas, auditorías o reportes, asigná un rol administrativo que corresponda.

Propietario y Administrador pueden consultar [Onboarding Your Team Members](https://www.shelf.nu/knowledge-base/onboarding-your-team-members) para el proceso completo. No compartas cuentas: los roles y la actividad son más útiles cuando cada integrante usa su propia identidad.

**Importante para Base:** puede solicitar una reserva propia, pero un Administrador completa la entrega y la devolución. **Autoservicio** puede operar sus propias reservas según la configuración del espacio. Consultá la [matriz oficial](https://www.shelf.nu/knowledge-base/user-roles-and-their-permissions) si hay dudas antes de asignar un rol.

## 6. Elegí entre custodia y reserva

Ambas opciones registran responsabilidad, pero responden a situaciones distintas:

- Usá **custodia** cuando una persona queda a cargo de un activo sin una fecha definida de devolución: por ejemplo, una notebook de trabajo.
- Usá **reserva** cuando el equipo necesita prever una entrega y devolución en fechas concretas: por ejemplo, equipos para un evento.

Para el primer activo, asigná custodia sólo si ya está entregado a una persona. El detalle está en [Custody Feature for Long-Term Equipment Lend-Outs](https://www.shelf.nu/knowledge-base/custody-feature-for-long-term-equipment-lend-outs). Las reservas se cubren en [Operación habitual](02-operacion-habitual.md).

## 7. Personalizá sólo lo necesario

Cuando los datos básicos ya funcionan, podés crear campos personalizados: por ejemplo, número interno, fecha de calibración o responsable de mantenimiento. No hace falta configurarlos para comenzar.

Abrí [Adding Additional Fields to Assets](https://www.shelf.nu/knowledge-base/adding-additional-fields-to-assets) si necesitás incorporar uno. Si ese dato sólo aplica a cierto tipo de activo, consultá también [Linking Custom Fields to Categories](https://www.shelf.nu/knowledge-base/linking-custom-fields-to-categories).

## Comprobación de los primeros pasos

Antes de seguir hacia la operación diaria, verificá que podés responder estas preguntas sin buscar una planilla externa:

- ¿Tenemos al menos un activo correctamente registrado?
- ¿Podemos identificar su categoría, etiqueta o ubicación?
- ¿Sabemos quién es responsable si ya fue entregado?
- ¿Cada integrante tiene el rol que necesita, sin permisos de más?
- ¿Sabemos cuándo usar custodia y cuándo una reserva?

Si todas son afirmativas, continuá con [Operación habitual](02-operacion-habitual.md): búsqueda, custodia, reservas, QR, calendario y recordatorios. La [base de conocimiento oficial](https://www.shelf.nu/knowledge-base) mantiene el detalle de cada función.
