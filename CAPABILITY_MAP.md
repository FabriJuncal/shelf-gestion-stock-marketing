# CAPABILITY_MAP

Relevamiento local: 2026-09-22. Describe capacidades observadas y su tratamiento recomendado. No habilita funciones ni autoriza implementación. El estado del entorno remoto no fue consultado como parte de este discovery.

## Clasificación

- **KEEP:** conservar la solución actual.
- **ADD:** incorporar una capacidad faltante y justificada; indicar si ya se agregó como documentación o si es futura.
- **WRAP:** integrar el proceso existente mediante una capa documental mínima, sin sustituirlo.
- **IMPROVE:** completar o verificar una capacidad existente con una necesidad concreta.
- **REPLACE_LATER:** reemplazo futuro justificado; ninguna capacidad recibe esta clasificación en este discovery porque no hay evidencia suficiente.
- **IGNORE:** fuera del alcance/necesidad actual; no significa eliminar código existente.
